Forward Approval (Green)

Request moves sequentially to the next higher tier upon approval.

Intelligent Rollback (Amber)

Rejections at Tiers 2-4 return the request to the previous tier for correction.

Full Rejection (Red)

Tier 1 Guide rejection marks the request as permanently REJECTED.
